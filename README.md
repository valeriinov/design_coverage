# design_coverage

Generator and annotation packages for design coverage markdown output.

## design_coverage

Import into your pubspec `dev_dependencies` section.

```yaml
dev_dependencies:
  design_coverage:
    git:
      url: https://github.com/valeriinov/design_coverage.git
      path: packages/design_coverage
      ref: 0.1.0
```

## design_coverage_annotation

Import into your pubspec `dependencies` section.

```yaml
dependencies:
  design_coverage_annotation:
    git:
      url: https://github.com/valeriinov/design_coverage.git
      path: packages/design_coverage_annotation
      ref: 0.1.0
```
